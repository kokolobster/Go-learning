## Словарик (вернётесь сюда по ходу)

- **Пакет (package)** — группа Go-файлов, которые лежат в одной папке и работают
  вместе. «Пакет »main"» — это всегда точка входа программы.
- **Импорт (import)** — подключение чужих пакетов (например, `fmt` для печати).
- **Функция (func)** — именованный кусок кода, который можно вызвать.
- **Сигнатура** — «лицо» функции: имя, аргументы и что она возвращает:
  `func greet(name string) string` значит «принимает строку, возвращает строку».
- **Тип (type)** — какое значение хранит переменная: число, строка, булево...
- **Вывод типов** — Go сам понимает тип по значению: `x := 42` ← это `int`.
- **Строка (string)** — в Go это просто **байты**. Русский текст весит 2 байта
  на букву (UTF-8). Поэтому строки отлично подходят для «проталкивания» данных.
- **Руна (rune)** — одна «буква юникода»; это `int32`. Обычно итерация по строке
  даёт байты, а `for range` — уже руны.
- **GOPATH / рабочая область** — в современных версиях не важна: проект живёт в
  любом каталоге, у него свой `go.mod`.
- **Модуль** — единица дистрибуции Go: `go.mod` описывает имя модуля
  (здесь `petproj/phase0`) и версию языка. Все упражнения — один модуль.

# Глава 1 — День 1: пакеты, переменные, функции

Читаем Tour: [Welcome](https://go.dev/tour/welcome/1) → [Packages](https://go.dev/tour/basics/1) →
[Variables](https://go.dev/tour/basics/8) → [Functions](https://go.dev/tour/basics/4).

## Конспект

### 1. Минимальная программа

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет!")
}
```

- `package main` — точка входа. Любой другой код мы уже не запускаем напрямую,
  а подключаем как пакет.
- `import "fmt"` — берём из стандартной библиотеки печать.
- `func main()` — **отсюда стартует программа**. Это единственная «кнопка».

### 2. Переменные и вывод типов

```go
var имя string = "мир"   // явно: тип string
имя2 := "мир"            // коротко: тип выводится
```

- `:=` — объявить и сразу присвоить (работает только внутри функций).
- `var` без значения даёт «нулевое» значение: `0` для чисел, `""` для строк.

### 3. Функции

```go
func greet(name string) string {
    return "Привет, " + name
}
```

- Имя аргумента (name) → тип (`string`) → тип результата.
- Если функция ничего не возвращает — тип результата не пишем.
- `+` для строк — это конкатенация. **В сетях опасность**: сложение строк при
  построении пакетов — источник несовместимости с байтовым «по-настоящему».
  Больше об этом в упражнении 01.

### 4. Печать

```go
fmt.Println(1, "два") // 1 два — аргументы через пробелы, перевод строки
fmt.Printf("%d байт %q\n", 2, "сеть") // форматирование по шаблону
```

`%d` — целое число, `%s` — строка, `%q` — строка в кавычках «для отладки»,
`%v` — «любое значение» (универсальный). Запомните `%q`: когда дойдём до
проб безбайтовых участков трафика, он покажет невидимые символы.

## Почему это нужно для сети

- **Строка = байты.** Дейтаграмма TCP — это тоже последовательность байтов.
  «Строка в Go» — уже почти «пакет данных», хоть и недвоичный.
- **Функции как абстракция потока.** `greet(name)` — это, по сути, «принять вход,
  вернуть выход». Именно так устроены сетевые фильтры: байты на вход, байты на выход.
- **`fmt.Printf` с `%q`** пригодится на сокетах как «рентген» трафика — увидите,
  что ушло ровно по проводу.

## Самопроверка (сначала ответьте вслух/на бумаге)

<details>
<summary>1. Чем <code>var s string</code> отличается от <code>s := ""</code>?</summary>

Кратко: оба дают пустую строку. Разница: `var` явно указывает тип и может быть
без присваивания; `:=` — короткая запись с выводом типа (работает только внутри
функции).
</details>

<details>
<summary>2. Что выведет <code>fmt.Printf("%q", "сеть")</code>?</summary>

Кавычки и сам текст: `"сеть"`. `%q` печатает «строка для отладки», с экранированием
и в кавычках.
</details>

<details>
<summary>3. Почему в Go русский символ занимает не 1 байт?</summary>

Go-строки хранят UTF-8. Большинство кириллических букв кодируются 2 байтами.
Длина строки в байтах — это `len(s)`, а не количество «букв».
</details>
